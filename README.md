# javascript-lotto-precourse : 로또

## 프로젝트 설명

사용자가 입력한 금액에 따라 로또를 자동 발행하는 간단한 로또 발매기입니다.
각 로또는 1~45 범위의 중복되지 않은 6개의 숫자로 구성됩니다.
**당첨 번호(6개)** 와 **보너스 번호(1개)** 를 입력받아 사용자의 로또와 비교합니다.
일치 개수에 따라 1등부터 5등까지 등수를 판정하고 상금을 계산합니다.
최종적으로 당첨 내역과 수익률을 출력하며, 잘못된 입력은 `[ERROR]`메시지와 함께 다시 입력을 받습니다.

## 주요 기능

- ### **로또 구매**
  - 사용자가 입력한 금액에 따라 자동으로 로또를 발행합니다.
  - 로또 1장의 가격은 1,000원이며, 구매 금액만큼 로또를 생성합니다.
- ### **로또 번호 생성**
  - 1~45 사이의 숫자 중 중복되지 않는 6개의 숫자를 무작위로 추출합니다.
  - 각 로또는 랜덤한 숫자 조합으로 생성됩니다.
  - 번호 개수, 범위 중복 여부를 검증하여 올바른 로또만 생성되도록 합니다.
- ### **당첨 번호 입력 및 형식 검증**
  - 사용자의 입력값(구매 금액, 당첨 번호, 보너스 번호)의 형식과 범위를 검사합니다.
  - 잘못된 입력 시 `[ERROR]` 메시지를 출력하고, 해당 단계부터 다시 입력받습니다.
- ### **당첨 결과 판별**
  - 사용자의 모든 로또 번호를 당첨 번호와 비교하여 일치 개수를 계산합니다.
  - 일치한 개수 및 보너스 번호 여부에 따라 1등 ~ 5등을 판정합니다.
- ### **결과 출력 및 수익률 계산**
  - 각 등수별 당첨 개수와 총 상금을 출력합니다.
  - 총 수익률을 계산하여 게임 결과를 표시합니다.

## 기능 목록

- ### **로또 구매**
  - 사용자로부터 구입 금액을 입력받는다.
  - 구입 금액에 따라 로또 개수를 계산한다.
  - 해당 개수만큼 로또를 생성한다.
  - 구입 금액은 검증
    - 1,000원 단위 검증
    - 양의 정수 검증
- ### **로또 번호 생성 및 검증**
  - 1~45 범위의 숫자 중 중복되지 않은 6개 숫자를 무작위로 뽑는다.
  - `LOTTO` 객체 생성 시 `#validate()`를 통해 아래를 검증한다.
    - 번호 개수(6개) 검증
    - 범위(1~45) 검증
    - 숫자 중복 여부 검증
  - 검증 실패 시 `[ERROR]` 메시지와 함께 `Error`를 발생시킨다.
  - 검증 실패 후 다른 로또 번호를 다시 뽑는다.
- ### **당첨 번호 입력 및 검증**
  - 사용자로부터 당첨 번호 6개를 입력받는다.
  - 입력값 형식을 검증하고 실패 시 `[ERROR]`메시지와 함께 `Error`를 발생시킨다.
    - 숫자 여부 검증
    - 범위(1~45) 검증
    - 중복 여부 검증
    - 쉼표(,)가 아닌 다른 구분자 여부 검증
    - 번호 개수(6개) 검증
  - 사용자로부터 보너스 번호 1개를 입력받는다.
    - 숫자 여부 검증
    - 범위(1~45) 검증
    - 중복 검증
- ### **당첨 결과 판별**
  - 각 생성한 로또 번호를 당첨 번호와 비교하여 일치 개수를 계산한다.
  - 일치 개수와 보너스 번호 일치 여부에 따라 등수(1~5등)를 판정한다.
  - 등수별 당첨 횟수를 집계한다.
- ### **결과 출력 및 수익률 계산**
  - 등수별 당첨 개수와 상금을 출력한다.
  - 총 당첨금 합계를 계산한다.
  - `수익률 = (총 당첨금 / 구입 금액) x 100`을 계산한다.
  - 소수점 둘째 자리까지 반올림하여 표시한다.
  - 수익률을 출력한다.
- ### **예외 처리**

  - 잘못된 입력 발생 시 `[ERROR]`로 시작하는 메시지를 출력한다.

    | 예외                                     | 에러 메시지                                 |
    | ---------------------------------------- | ------------------------------------------- |
    | 번호 개수(6개)가 아닌 경우               | `[ERROR] 로또 번호는 6개입니다.`            |
    | 로또 번호 범위(1~45)가 아닌 경우         | `[ERROR] 로또 번호 범위는 1~45 입니다.`     |
    | 숫자가 중복된 경우                       | `[ERROR] 로또 번호는 중복될 수 없습니다.`   |
    | 쉼표(,)가 아닌 다른 구분자로 입력된 경우 | `[ERROR] 구분자는 쉼표(,)만 가능합니다.`    |
    | 구입 금액의 단위가 1,000원이 아닌 경우   | `[ERROR] 구입 금액의 단위는 1,000원입니다.` |
    | 구입 금액이 양의 정수가 아닌 경우        | `[ERROR] 구입 금액은 양의 정수입니다.`      |
